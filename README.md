# Measurement Error and Misclassification

Statistical methods and R code developed by Dr. Molin Wang's group and collaborators for correcting measurement error and misclassification in epidemiologic studies.

## Available methods

| Method | Language | Purpose |
| --- | --- | --- |
| [Regression calibration](regression-calibration/) | R | Correct exposure measurement error using regression calibration with validation study data. |
| [Longitudinal analysis with GEE](longitudinal-gee/) | R | Correct exposure measurement error in GEE analyses of time-varying exposures and longitudinal continuous outcomes. |
| [Propensity score-adjusted Cox regression](cox-misclassification/) | R | Correct exposure misclassification in Cox regression analyses adjusted for propensity scores. |
| [Partial population attributable risk](ppar-misclassification/) | R | Correct misclassification bias in estimation and inference for partial population attributable risk (PPAR). |
